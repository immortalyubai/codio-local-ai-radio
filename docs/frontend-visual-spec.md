# Claudio FM Frontend Visual Spec

## 1. 产品前端定位

Claudio FM 是一个竖向 AI 电台设备界面。它的核心感受应该是：用户正在面对一台 24 小时在线的私人 AI 电台终端。

Claudio FM 不是普通播放器，不是 dashboard，不是后台控制台，也不是普通聊天 App。播放器只是电台正在播出的窗口，聊天区才是用户和 AI 主持人 Claudio 建立长期音乐偏好的入口。

## 2. 整体结构

页面第一眼只显示一个居中的电台设备卡片。

整体结构固定为：

- 上半部分：电台播放器
- 下半部分：Claudio 主持人聊天区

桌面端设备卡片宽度应控制在 430px-520px，保持窄长设备感。手机端应自适应屏幕宽度，并保留必要边距。

不要把页面扩展成产品官网、后台系统或多栏 dashboard。

## 3. 视觉风格

Claudio FM 的视觉关键词：

- 深色
- 复古点阵屏幕
- 终端感
- 电台设备感
- 克制、高级

可以使用点阵纹理、细边框、低透明度分隔线、轻微内阴影和设备感背景。不要使用过度霓虹、夸张渐变、大面积装饰图形或营销页式视觉。

## 4. 上半部分播放器规范

播放器区域必须像电台正在播出的窗口，而不是推荐系统卡片。

播放器区域需要包含：

- 大号时间
- 日期 / 星期 / 天气
- ON AIR
- 当前节目段
- Now Playing
- 歌曲名 / 艺术家
- Claudio Selection
- 播放控制
- 进度条

播放器文案应使用电台语境。禁止出现：

- 推荐：
- Open Host
- Open Radio
- mock
- planner
- dashboard 术语

## 5. 下半部分聊天区规范

聊天区是用户和 Claudio 建立音乐偏好的核心区域。

聊天区需要包含：

- Claudio 在线状态
- Connected to Claudio server
- 主持人消息在左
- 用户消息在右
- 双方头像
- 气泡式对话
- 底部输入框
- 反馈小标签

聊天内容应该像电台主持人自然口播，不要展示系统分析字段、推荐理由面板或表格化信息。

## 6. 主持人 Hover Card 规范

Claudio 头像 Hover Card 是主持人的小型音乐人格卡片。

Hover Card 需要体现：

- Claudio 音乐人格
- 口味标签
- MEMORY 数量
- ON AIR 24/7

桌面端通过 hover 显示。手机端后续可支持点击显示，但不能做成全屏 Modal、设置页或 dashboard。

## 7. 响应式规范

桌面端：

- 电台设备卡片居中
- 保持 430px-520px 的窄长比例
- 不出现外层官网式标题或导航

手机端：

- 自适应宽度
- 不横向滚动
- 输入区不被遮挡
- 卡片内容不裁切
- 长歌曲名、标签和按钮必须 truncate 或自然换行

## 8. 绝对不要出现的东西

Claudio FM 前端绝对不要出现：

- 产品官网首页
- 顶部导航
- 大面积表单
- 推荐理由 dashboard
- 音乐偏好设置卡片
- 系统分析字段
- 默认 HTML 样式
- 白底页面

任何后续前端修改都必须优先保持 Claudio FM 是一个深色、复古、竖向的 AI 电台设备。
